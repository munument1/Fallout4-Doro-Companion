# Doro Follower 0.2.6

레드 로켓 주유소에서 만나는 도로롱 독립 동료 모드입니다.
도로롱을 활성화하면 동행, 대기, 물건 보관, 레드 로켓 귀환을 선택할 수 있습니다.
도그밋과 기존 동료를 강제로 해산시키지 않습니다.

## 이번 버전

- 도로롱 전용 스켈레톤과 축소한 이동 충돌을 적용했습니다.
- 공격이 정상 작동한 test17의 공격 설정과 공격력을 유지합니다.
- 시험 명령, 전투 진단창, 진단 로그를 제거했습니다.
- 플레이어 레벨 1배 연동을 유지하고 기존 100레벨 상한을 65535로 확장했습니다.
- RC1에서 저장된 기본 공격력 0을 최초 로드 시 복구합니다.
- 기존 머리 탈, 의상, 화학작업대 무료 제작 자산을 유지합니다.

## 설치 및 업데이트

1. 게임을 완전히 종료합니다.
2. 기존 Doro 테스트 버전, RC 버전, UI2 패치를 비활성화합니다.
3. `DoroFollower_FO4_0.2.6.zip`을 모드 관리자로 설치합니다.
4. `DoroFollower.esp` 하나를 활성화합니다. 별도 `DoroCostumes.esp`를 중복 활성화하지 마세요.

이 버전은 **Full ESP**입니다. 초기 ESP-FE 테스트 버전과 구분하세요.
test17/RC 계열의 기존 FormID를 유지하며, 업데이트를 위해 세이브를 삭제할 필요는 없습니다.
명령 메뉴는 전투 중 열리지 않습니다.

## 참고

도그밋 수준으로 피해를 낮췄던 RC1 변경은 취소했습니다. 공격력은 강한 test17 설정입니다.
레벨 연동에 별도의 레벨별 공격력 보너스는 추가하지 않았습니다.
게임 적용 파일은 RC2와 동일하며, 정식 배포 전환에서는 문서와 검증 메타데이터만 변경했습니다.
전투 및 충돌 개선의 사용자 확인은 test17 기준입니다. 자동 검사는 게임 내 동작 검증을 대신하지 않습니다.
