# test15 전투 수정 — 2026-09-08

사용자가 제공한 test14를 기준으로 수정했다. 기존 0.2.4 ESP 생성기를 다시 실행하지 않고 test14의 전체 레코드와 자산을 보존했다.

## 문제와 변경

test14에는 피격마다 StartCombat을 다시 호출하는 경로, None/검색 상태를 아군으로 간주할 수 있는 StopCombat 조건, 전투 중 Setup에서 패키지를 재평가하는 경로가 남아 있었다. 공격 선택을 방해할 수 있는 이 개입을 줄였다. 단일 근본 원인이 입증된 것은 아니다.

- 이미 전투 중이면 StartCombat을 다시 호출하지 않는다. 엔진의 전투 진입 반영 전 중복 요청도 1초 제한한다.
- 전투 상태 1의 살아 있는 명시적 대상이 실제 현재 타깃이면서 보호 대상일 때만 아군 보호 StopCombat을 호출한다.
- Setup에서 Follow/Wait 패키지를 재평가하는 작업은 비전투 중에만 한다.
- 독립 메시지 메뉴 동료의 teammate favor 허용을 끄고 남은 favor 상태를 정리한다.
- 자체 구형 대화 씬 080D가 실행 중이면 종료한다. 다른 모드의 씬은 종료하지 않는다.
- 이미 reference scale=1이면 SetScale을 반복 호출하지 않는다.
- Combat status 메뉴와 전투 중 활성화 시 상태창을 추가했다. 호출 횟수, 아군 보호 중지 횟수, 타깃·거리·패키지·씬·favor·bleedout 등을 표시한다.

아군 필터, 동료 모드의 전투 AI·전투 스타일·공격 데이터, 기존 모델·확정 의상·제작법은 보존했다. 이제 공격이 나오는지 사용자의 인게임 테스트가 필요하다.

## 패키지

- test15A_CombatHotfix: 기존 Race height 0.42인 우선 테스트본.
- test15B_HeightControl: A와 동일하되 Race 남녀 높이만 1.0인 크기 대조본. 크게 표시되는 것은 의도한 비교 조건이다.

두 버전을 동시에 설치·활성화하지 않는다. 게임을 완전히 종료하고 버전을 바꾼 뒤 같은 원본 테스트 세이브에서 같은 적을 상대로 비교한다. 테스트 중 저장한 세이브를 다음 대조군의 시작점으로 사용하지 않는다. 기존 세이브나 모드를 삭제할 필요는 없다.

A가 공격하면 이번 변경 묶음이 효과가 있는 것이다. A는 실패하고 B만 성공하면 크기 관련 조건을 우선 조사한다. 두 경우 모두 어떤 단일 필드가 원인인지까지 즉시 확정할 수 없다. 둘 다 실패하면 Combat status 화면을 받아 타깃/패키지/씬 상태와 Race ID·공격 graph 경로를 이어서 검사한다.
