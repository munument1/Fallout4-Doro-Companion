## 확인된 상태

- 사용자 확인: 게임 내 도로롱 외형은 표시됨.
- 사용자 최신 보고: 도로롱을 활성화해도 대화가 시작되지 않음.
- 사용자 최신 보고: 화학작업대에 제작 카테고리가 보이지 않음.
- 설치 조사: MO2 Default_Profile에서 0.2.3과 0.2.4 폴더가 모두 활성화되어 있고 0.2.4가 높은 우선순위임. 설치된 ESP 해시는 최신 빌드와 일치함.
- 설치 조사: DoroCostumes.esp는 mods/overwrite 검색 결과에 없고 plugins.txt에도 없음. 별도 의상 패키지 미설치가 카테고리 문제의 우선 원인임. 설치 후 레시피 동작은 추가 확인 필요.
- 로컬 모델 검사: 중복 정점의 가중치를 통일한 뒤 검사한 애니메이션 프레임에서 이음새 간격 0. 실제 게임의 달리기 변형과 전투 행동은 재확인 필요.

## 대화 구현

독립 QUST/SCEN/DIAL/INFO 레코드를 생성하며 Gorilla Follower의 대화 구조를 참고했습니다. 영입은 자체 상태 전환으로 처리합니다. 기존 도그밋/동료를 해산시키는 바닐라 SetCompanion/DismissCompanion 호출은 사용하지 않습니다.

주요 로컬 Form ID: NPC 803, 배치 참조 80B, 대화 퀘스트 80C, 씬 80D, 인사 토픽 828, 인사 INFO 829, 대화 대기 패키지 82A, 음성 유형 82B. 실제 콘솔 ID에는 로드 순서 접두사가 필요합니다.

퀘스트 단계: 10 영입, 20 대기, 30 거래, 40 해산. 스크립트는 AllowPCDialogue와 별칭 바인딩을 시도하고 네이티브 인사 토픽을 통해 씬 진입을 기대합니다. 여전히 무반응이므로 구현 성공으로 간주하면 안 됩니다.

## 유지할 사용자 결정

- 소환 수류탄 DOROball 방식은 취소.
- 입을 벌리는 변경은 취소. 원본 닫힌 입 유지.
- 플레이어 의상은 전신이 아닌 머리 탈.
- 도그밋 의상은 제작 후 취소 요청이 있었고, 이미 만든 것은 테스트하겠다는 후속 응답이 있었음. 추가 개발보다 머리 탈과 동료 문제를 우선함.
- 세이브 초기화나 삭제를 해결책으로 단정하지 않음.

## 재현성 제한

현재 스크립트 모음은 자동화된 단일 빌드 시스템이 아닙니다. 특히 package_v02.py는 0.2용 패키징 스크립트이므로 최신 0.2.4 패키징 도구로 사용하면 안 됩니다. 참고 레코드 JSON, 게임 원본, 외부 모드 자산 및 도구 의존성은 공개 저장 대상에서 제외되어 있습니다.
